# Contributing

Thanks for helping make VisualForge more useful.

- Keep instructions compatible with both Claude Code and Codex where possible.
- Never imply an image backend is universally available or unlimited-free.
- Prefer small, testable workflows and dependency-light scripts.
- Document platform assumptions and cost implications.
- Do not commit API keys, private images, generated model weights, or huge binary assets.
- Test scripts with valid and invalid inputs before submitting changes.

For feature proposals, describe the user problem, expected behavior, supported backend, and failure modes.
