# Asset quality checklist

## Visual quality
- [ ] Subject and focal point are clear at intended size.
- [ ] Composition supports the page layout and crop.
- [ ] No obvious malformed anatomy, duplicated objects, or rendering artifacts.
- [ ] Color, lighting, and detail level fit the product's existing visual language.
- [ ] Text is absent unless requested; requested text is checked carefully.
- [ ] Asset set feels consistent without making every image identical.

## Technical quality
- [ ] File exists at the intended path.
- [ ] Format opens correctly and matches the requested output.
- [ ] Dimensions and aspect ratio are suitable.
- [ ] Transparency is actually present if requested.
- [ ] File size is reasonable for its role.
- [ ] References, imports, and alt text are correct when integrated.
- [ ] Existing assets were not silently overwritten.

## Trust and cost
- [ ] Actual backend is reported accurately.
- [ ] No unapproved paid service or large model download was used.
- [ ] Model/source licensing and attribution needs were considered.
