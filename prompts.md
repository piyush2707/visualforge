# Example requests

## Website hero
“Inspect the site's current typography and palette. Create a wide hero illustration with one clear focal point, generous negative space on the left for headline text, no embedded text, and a 16:9 composition. Use an available no-extra-API-cost backend if possible. Save to `public/images/hero-visual.png`; do not overwrite existing files.”

## Cohesive illustration set
“Create four onboarding illustrations for: discover, customize, collaborate, and launch. Define one shared visual system first. Keep line weight, palette, lighting, and perspective consistent. Save each asset separately and record prompt and dimensions in `assets/manifest.json`.”

## Image edit
“Edit `public/images/product.png` to use a transparent background. Preserve the exact product silhouette, label, color, and camera angle. Save to a new filename, verify alpha transparency if possible, and leave the original unchanged.”

## No raster backend available
“Check whether this environment has an image tool or configured local backend. If not, create a clean editable SVG illustration if that suits the brief. Clearly report that you used SVG rather than raster image generation.”

## Asset audit
“Inspect all images referenced by this project. Report missing files, unusually large assets, repeated assets, and images with missing alt text. Do not delete or replace anything without showing me the proposed changes first.”
